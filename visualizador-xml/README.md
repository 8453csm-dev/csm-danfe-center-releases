# CSM Visualizador XML — Canal de Atualizações

Este diretório público contém somente o manifesto e os pacotes de atualização do **CSM Visualizador XML**.

- O código-fonte principal permanece no repositório privado da CSM.
- O aplicativo consulta `latest.json` por HTTPS.
- Cada pacote é validado por SHA-256 antes de ser aplicado.
- A publicação do Visualizador não depende de GitHub Actions ou runner dedicado.

Versão-base do canal: **3.0.1**.
