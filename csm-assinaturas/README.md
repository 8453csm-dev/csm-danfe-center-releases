# CSM Assinaturas — Atualizações

Canal público de atualização automática do CSM Assinaturas.

Este diretório contém somente o manifesto e os pacotes compilados usados pelo botão **Verificar atualizações**.

Não são publicados e-mails, imagens de colaboradores, históricos, senhas ou o diretório `Repositorio_CSM`.
